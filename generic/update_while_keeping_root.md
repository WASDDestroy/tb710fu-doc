# 保留 Root 增量更新

> [!important]
> 适合**解锁设备**的 LKM 模式和 Magisk，GKI 模式和 APatch 默认不支持增量更新！

- 假设你没有刷降压超频、第三方 Recovery 等镜像，如果有就先还原这些修改。
- 假设你在系统版本 1.5.04.384 通过修补镜像后 fastboot 刷入获取了 Root ，现在要依次更新到 1.5.04.392 和 1.5.04.414 。从 384 更新到 392 是**第一次系统更新**。第二次系统更新是 392 到 414 .
- 如果你通过 `fastboot boot kernelsu_gki.img` 临时获取 Root 后让管理器 `直接安装` ，则可以直接跳到第二步。
## 第一次系统更新：建立循环

1. 关闭所有模块，重启
2. 找到你保留的当前版本的 init_boot.img ，本教程一直倡导刷机前备份，如果你没有遵循这一条请自行寻找镜像。
3. 刷入 init_boot.img 到活动插槽或者两个插槽。这里提供使用 `dd` 命令的形式：
   ```shell
   su
   current_slot=$(getprop ro.boot.slot_suffix)
   dd if=./init_boot.img of=/dev/block/by-name/init_boot${current_slot}
   exit
   ```
4. 正常进行系统更新
5. 系统更新完毕后**不要重启**，点击管理器中的 `运行中` 或者 `安装` ，然后点击 `安装到另一个槽位` ，确认警告后刷入。如果你不放心，可以先不重启，再点击一次 `直接安装` ，确保两个插槽都存在活动镜像，然后利用系统更新 APP 重启。

## 第二次系统更新：七转，八起

1. 关闭所有模块，重启
2. 打开管理器，点击 `设置` （KernelSU） 或者翻到页面最下方 （Magisk） 找到 `卸载` ，点击后会出现两个选项，选择 `还原原厂映像` 。
3. 正常进行系统更新
4. 系统更新完毕后**不要重启**，点击管理器中的 `运行中` 或者 `安装` ，然后点击 `安装到另一个槽位` ，确认警告后刷入。如果你不放心，可以先不重启，再点击一次 `直接安装` ，确保两个插槽都存在活动镜像，然后利用系统更新 APP 重启。
