## 环境建议

本教程基于 Windows 11 专业版 24H2 和 25H2 写作。建议您使用 Windows 10 20H2 以及更高版本的系统以保证教程中的步骤和描述不会出现问题。

如果您使用 Linux 系统，可能无法使用 9008 相关软件。

此外，**不建议**在以下设备上执行刷机操作：

- 网吧电脑（驱动程序可能无法按预期工作，可能无法检测到处于 9008 模式的设备）
- 磁盘空间较小的电脑（无法正常下载或者解压刷机包）
- 内存小于等于 4GB 的电脑（程序运行可能由于需要频繁使用虚拟交换而变得缓慢，甚至可能崩溃）
- Windows 10 以下系统（无法保证本教程中所有工具可以在 Windows 8.1 及以下版本的操作系统中运行）
- 低性能 CPU 主机，例如只具备 2 个物理核心的因特尔奔腾或者赛扬处理器（运行现代操作系统将显得吃力、部分刷机软件性能要求高）

如果您的设备命中了上方一条或多条，请视情况升级操作系统、硬件配置、借用电脑或者购买新设备。
