## 环境建议

本教程基于 Windows 11 专业版 24H2 和 25H2 写作。建议您使用 Windows 10 20H2 以及更高版本的系统以保证教程中的步骤和描述不会出现问题。

如果您使用 Linux 系统，可能无法使用 9008 相关软件。

此外，**不建议**在以下设备上执行刷机操作：

- 网吧电脑（驱动程序可能无法按预期工作，可能无法检测到处于 9008 模式的设备）
- 磁盘空间较小的电脑（无法正常下载或者解压刷机包）
- 内存小于等于 4GB 的电脑（程序运行可能由于需要频繁使用虚拟交换而变得缓慢，甚至可能崩溃）
- Windows 10 以下系统（无法保证本教程中所有工具可以在 Windows 8.1 及以下版本的操作系统中运行）
- 使用非官方 Windows 镜像的电脑（命令行行为可能异常；可能存在后台服务阻止使用 USB 设备）
- 低性能 CPU 主机，例如只具备 2 个物理核心的因特尔奔腾或者赛扬处理器（运行现代操作系统将显得吃力、部分刷机软件性能要求高）
- 年事已高，接口生锈的电脑（和设备的链接不稳定，刷机过程中容易意外断开导致严重故障；电脑内部元器件老化，台式机等设备容易因外力等因素造成内部元件接触不良，无法正常工作）
- 只能在机械硬盘（HDD）进行文件操作的电脑，包括但不限于下面两种情况：
  - 电脑只配备了机械硬盘
  - 电脑配备了固态硬盘（SSD），但是固态硬盘存储空间不足，只能使用机械硬盘
  （这类设备使用机械硬盘导致文件 IO 性能低，且已经遇到过由于短期巨量读写损坏 HDD 的情况）
- 涉及重要业务的设备和工作设备（刷机操作可能导致重要业务中断，给您和您的组织和带来损失）

如果您的设备命中了上方一条或多条，请视情况升级操作系统、硬件配置、借用电脑或者购买新设备。

如果您的周遭环境满足下面的任意一条，同样不建议进行刷机：

- 电力供应不稳定，没有不间断电源或者笔记本电脑的电池健康度太低（意外断电可能导致设备陷入严重故障）
- 无法保证刷机过程不受到干扰，造成您必须断开连线或者关闭电脑（中断刷机可能导致设备陷入严重故障）
- 处于凌晨等时段（精神不集中，易犯低级错误）
- 处于工作环境、正在处理重要业务、操作危险机械等（精神不集中，易犯低级错误）
